# Portfólio | Daniel Kaiã

Projeto Final A1: site portfólio em HTML, CSS e JavaScript, responsivo, hospedado no GitHub Pages.

## Estrutura
- `index.html`: página inicial (precisa ficar na raiz para o GitHub Pages)
- `html/sobre.html`: página "Sobre mim"
- `css/style.css`: visual e responsividade
- `js/main.js`: menu, tema claro/escuro, digitação e formulário
- `images/`: `foto.jpg` (sua foto), `desenhos/`, `filmes/`, `livros/`
